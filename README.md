# CervantesMUN
Multifunctional website for the CervantesMUN Project 

## Instructions
Download the files, extract them and start by opening `main.html` (note that this doesnt really work on mobile, see below)

For a local web server you can try `python -m http.server 8000` in a terminal open on the website's root folder, then you can open the website on any device on the same network by using `http://192.168.X.X:8000` (find the IP with ipconfig on windows or ifconfig on unix based systems)
